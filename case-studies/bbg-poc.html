Financial Data Quality & Governance Framework

Hybrid-ML validation for ownership & 13F filing data · Python, synthetic data

github.com/tolstii/BBG-POC

A proof-of-concept governance framework for the hardest kind of financial data to validate: ownership and 13F filings, where the same holder appears under a dozen name variants and the defects are semantic, not structural. It pairs statistical and deep-learning anomaly detection, routes the uncertain cases to a human, and resolves messy entities with NLP and a graph. Built clean-room on synthetic data.

The problem

Ownership data breaks rules that schema checks never see. A filing is well-formed and still wrong: the same institution filed under three spellings, a position is an order of magnitude off but inside the column's range, a 13F and a Form 4 disagree on the same holder. Rule-based validation either misses these or drowns the analyst in false positives, because a fixed threshold can't tell a real anomaly from normal variation across 500K+ data assets.

Approach

The framework treats detection as a layered pipeline, cheapest checks first, with the model reserved for what rules can't judge.

raw filings→ NLP extract (spaCy)→ graph resolve (NetworkX)→ DAMA profiling→ hybrid detector→ active learning

Hybrid anomaly detection

An Isolation Forest flags point anomalies (a single value that doesn't belong) and an LSTM flags sequence anomalies (a holding whose trajectory over quarters is wrong). Combined, they catch both "wrong now" and "wrong pattern," which neither model does alone.

Active learning, so the model improves where it is weakest

Instead of retraining on random samples, the pipeline routes its most uncertain cases to a human reviewer, and those confirmed labels feed the next training round. The loop is guarded: the model learns from human-confirmed labels, not from its own prior guesses.

NLP and graph resolution for unstructured filings

spaCy extracts entities and holdings language from free-text filings; a NetworkX graph resolves which filings refer to the same underlying holder across aliases, subsidiaries, and spellings, so transitive matches resolve cleanly (if A = B and B = C, then A = C).

Profiling as the foundation

A 12-category profiling framework extending the DAMA dimensions measures completeness, accuracy, consistency, and timeliness per field, producing the baselines that set thresholds and the features the models learn from.

What the POC reports

63% fewer false positives vs rule-based +30% anomaly accuracy from active learning 500K+ synthetic data assets 12-category DAMA-extended profiling Streamlit dashboard, 12 live metrics
These are the POC's own results on synthetic data, not a production benchmark. The point of the project is the architecture: a defensible way to combine statistical and deep-learning detection with a human-in-the-loop, so the model assists judgment instead of replacing it.
